GHOST MESSAGES — Android project

КАК ПОЛУЧИТЬ APK С ТЕЛЕФОНА:
1. Распакуй ZIP.
2. Создай репозиторий на https://github.com (кнопка New).
3. Загрузи ВСЕ файлы и папки проекта в корень репозитория (Add file -> Upload files).
   Важно: включи скрытую папку .github. Если файловый менеджер её не показывает,
   используй GitHub в браузере и загрузи .github/workflows/build-apk.yml отдельно,
   создав папки через Add file -> Create new file.
4. Нажми Commit changes.
5. Открой вкладку Actions в репозитории.
6. Дождись зелёной галочки у "Build Ghost Messages APK".
7. Открой завершённую сборку и скачай Artifact "Ghost-Messages-APK".
8. Распакуй скачанный архив и установи app-debug.apk.

ВАЖНО О РАБОТЕ:
- Приложение сохраняет текст уведомлений WhatsApp и Telegram локально на телефоне.
- В настройках Android нужно вручную разрешить доступ к уведомлениям.
- Оно НЕ взламывает мессенджеры и не получает историю чатов с их серверов.
- Сохраняется только текст, который Android передал в уведомлении. Если предпросмотр
  отключён, сообщение скрыто, уведомление не пришло или текст обрезан — восстановить его нельзя.
- Метка "уведомление исчезло" означает только, что уведомление было удалено/снято.
  Android не сообщает надёжно, удалил ли отправитель сообщение для всех или пользователь
  просто смахнул уведомление. Поэтому это не доказательство удаления сообщения.
- История хранится локально; приложение не отправляет её на сервер.
- Не используй приложение для чтения чужих уведомлений без согласия владельца устройства.

Проект рассчитан на Android 8.0+.
